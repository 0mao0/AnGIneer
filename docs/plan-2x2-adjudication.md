## 5. 判定规则（锁死）

1. **D−C ≥ +12 条且两轮方向一致** → Schema 对新模型仍有增量 → 按 §5 建 P1；
2. **D−C ≤ 0 且 B−A ≥ +12** → 确认弱模型补丁 → 停通用五型路由，只留确定性件；
3. S1 类收益消失而聚合/计算类仍有收益 → 只留聚合/计算/校验，不做完整五型体系；
4. 池化后仍不足 +12 → 证据不足，维持现状（不建 P1，确定性件保留）；
5. 主判据在 229 条池；±12 条门槛 ≈ 5pp，已对齐单轮 ±5 题/12% 噪声地板的两轮池化容差；
6. 无论裁决结果，施工主线确定性件（对账/代码统计/引用/数值槽/安全终态）均保留。

### 7.4 裁决（按 §5 锁死规则逐条核对）

- 规则 1（D−C ≥ +12 且两轮一致）：D−C=**+11.0 < +12**（方向一致但差 1 条）→ 不触发；
- 规则 2（D−C ≤ 0 且 B−A ≥ +12）：D−C=+11 > 0 → 不触发；
- 规则 3（S1 收益消失而聚合保留）：两子集 D−C 均 +11~+12，无此形态 → 不触发；
- 规则 4（池化未过 +12）→ **触发：证据不足，维持现状——不建 P1 五型体系，确定性件保留。**

**裁决定性**：Schema 增益随模型变强明显收窄（+33 → +11，D≈B 差 +1 且方向不一致，
天花板约 29.5%），呈「弱模型补丁」形态但 **D−C 卡在门槛下一格**，按预注册纪律判
「证据不足」而非「补丁确认」。**不建运行时分类器（P1），确定性件（对账/代码统计/
引用/数值槽/安全终态）全部保留**；聚合规格（S2 图纸）维持 016/041 两张手工图纸，
不扩自动化。若后续出现新模型代际（更强），本实验的 D−C 门槛可原样复测。
