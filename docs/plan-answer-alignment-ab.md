# 「对齐判断强化」A/B 预注册（2026-11-08）

- 决策问题：在**保留拒答能力**的前提下，把「覆盖判定」对齐到证据优先（证据中出现所问核心对象即作答），
  能否提升 FinanceBench 得分而不损伤拒答集表现
- 状态：预注册落稿，实验未启动
- 纪律：只动**运行级 answer_format 注入**（POST 参数，生产默认提示词零改动）；同代码同判官同题；
  判官异常 → 该题按 skipped 纪律退出分母并如实报

## 1. 臂定义

| 臂 | 提示词 | 说明 |
|---|---|---|
| A（基线） | 现行默认 | **复用今日生产 run**：financebench `1c2f9814`（77/150）、refusal-v3 `e32136da`（26/33）——同代码（v0.3.10）、同日、同判官 |
| B（变体） | 默认 + 运行级 answer_format 注入（下方全文） | 今日生产环境新跑两组：financebench 150 + refusal-v3 33 |

**注入全文（B 臂）**：

```
【本次运行：对齐判断强化（优先于既有规则 3/16 的默认倾向）】
在做「对齐判断」前，先逐条核对证据中是否出现问题的核心对象（指标/数值/年份/条款名，含表格行、脚注、相邻句）：
1) 核心对象出现即视为「覆盖」或「部分覆盖」——必须作答：给出证据支持的答案并正常标注引用；
   证据不完整的部分明确标注（如「证据仅支持至…」），不得以「证据未直接陈述结论」「证据只与主题相关」为由整体拒答；
2) 仅当证据完全没有出现核心对象（主体/时间/指标均不符）时，才按既有规则拒答；
3) 禁止编造证据中未出现的数字、条款或结论；拒答能力保留。
```

## 2. 指标与判定规则（锁死）

- **主指标**：FinanceBench 150 正确题数。**采纳门槛 = B − A ≥ +5 题（≥3.3pp）**；
- **护栏 1（拒答能力）**：refusal-v3-39 正确题数 **B ≥ A − 2 题**（33 题噪声带 ±2-3；跌破即否决）；
- **护栏 2（假拒答下降）**：FinanceBench 上拒答型错题数应下降（A 基线 40 题拒答，含约 16 假拒答候选）；
- **护栏 3（判官）**：任一组 judge 失败 > 3 题 → 停批，不出结论；
- 判定：主指标达标且两护栏全过 → **采纳**（变体以默认关开关落代码，另批施工）；否则记录不采纳。

## 3. 观测口径

- A 臂逐题 quality 从生产库 `eval_run_detail` 读（run 1c2f9814 / e32136da，明细行现存）；
- B 臂跑批时逐题落 JSON（quality + scores + 答案头 + 是否拒答 + 拒答前证据数字命中），防单题 run 被清理机制删除；
- 假拒答判定（数字探针）：题目金标中的数字出现在证据里而答案拒答。

## 4. 执行

- 容器内直调 `suite_runner.start_eval_run(dataset_id, question_id, answer_format=注入全文)`，串行跑
  183 run（150+33），预计 40-60 分钟；
- 起跑前确认无在跑 run；跑完逐题落盘 `ab_answer_B.json`。

## 5. 结果（跑后追加，2026-11-08）

- **执行事故（已修复）**：首轮 137 run 因跑批入口 sys.path 残缺（`_spawn_worker` 把调用方
  sys.path 透传给 worker），worker 无法 import evals_runtime → 检索端口未注册 → 全部
  `guard_replaced_no_evidence`。补齐 services 路径后重跑，问题消失（evidences 15→30 正常）。
  事故批与本次 A/B 的单题 run 已从生产库清理（243 条），「上一轮对照」已加 `is_full_run`
  过滤防单题 run 污染。
- **FinanceBench 150（主指标）**：A 77/150 → **B 75/150，净差 −2 题（−1.3pp）——未达 +5 门槛，不采纳**。
  修复（A错B对）8 题 / 破坏（A对B错）10 题；B 臂拒答数 40 → 27（−13）——「更敢答」兑现了，
  但救回的 8 题被新增答错的 10 题抵消，净收益为零（−2 在 150 题噪声带内）。
- **拒答集护栏**：A 26/33 → B 25/33（−1，在 −2 容差内）→ 护栏通过（拒答能力未被破坏）。
- **结论**：拒答协议放宽对 FinanceBench 无显著改善且引入答题风险——**拒答纪律不是此类题的
  低垂果实**；假拒答候选即便强制作答也大多答不到点上。瓶颈仍是抽取与答案组织。
