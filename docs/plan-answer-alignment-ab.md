  能否提升 FinanceBench 得分而不损伤拒答集表现
- 状态：预注册落稿，实验未启动

## 1. 臂定义

| 臂 | 提示词 | 说明 |
|---|---|---|
| A（基线） | 现行默认 | **复用今日生产 run**：financebench `1c2f9814`（77/150）、refusal-v3 `e32136da`（26/33）——同代码（v0.3.10）、同日、同判官 |
| B（变体） | 默认 + 运行级 answer_format 注入（下方全文） | 今日生产环境新跑两组：financebench 150 + refusal-v3 33 |

**注入全文（B 臂）**：

```
【本次运行：对齐判断强化（优先于既有规则 3/16 的默认倾向）】
在做「对齐判断」前，先逐条核对证据中是否出现问题的核心对象（指标/数值/年份/条款名，含表格行、脚注、相邻句）：
1) 核心对象出现即视为「覆盖」或「部分覆盖」——必须作答：给出证据支持的答案并正常标注引用；
   证据不完整的部分明确标注（如「证据仅支持至…」），不得以「证据未直接陈述结论」「证据只与主题相关」为由整体拒答；
2) 仅当证据完全没有出现核心对象（主体/时间/指标均不符）时，才按既有规则拒答；
3) 禁止编造证据中未出现的数字、条款或结论；拒答能力保留。
```

## 2. 指标与判定规则（锁死）

- **主指标**：FinanceBench 150 正确题数。**采纳门槛 = B − A ≥ +5 题（≥3.3pp）**；
- **护栏 1（拒答能力）**：refusal-v3-39 正确题数 **B ≥ A − 2 题**（33 题噪声带 ±2-3；跌破即否决）；
- **护栏 2（假拒答下降）**：FinanceBench 上拒答型错题数应下降（A 基线 40 题拒答，含约 16 假拒答候选）；
- **护栏 3（判官）**：任一组 judge 失败 > 3 题 → 停批，不出结论；
- 判定：主指标达标且两护栏全过 → **采纳**（变体以默认关开关落代码，另批施工）；否则记录不采纳。
