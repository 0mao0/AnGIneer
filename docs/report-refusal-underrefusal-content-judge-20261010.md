## 局限

- n=10 单跑；拒答行为本身有抽签性（历史 39 题集同题跨 run 摆动 ±2~3 题）。
- 本判分只测「与公开 gold 的内容一致性」，不测出处纪律——「出处对不上」是 10/10 全体的既定事实。
- gold 为公开参考答案，个别题自身表述粒度粗（如 Yes./公式），判官按实质一致性兜底。
