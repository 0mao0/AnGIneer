## 0. 为什么立项

1. **组件级负收益信号（待重判确认）**：三臂对照【它声称，2026-09-26/27 两天同向】——39 道无答案题的拒答行为：
   臂2 朴素 RAG **79.5%**（31/39）＞ 臂3 金开卷 59.0%（23/39）＞ 臂1 全链 **56.4%**（22/39）。
   一个专门做的守卫不如一句通用提示词；修到臂2水平 ≈ 整体分 **+0.9pp**（纯缺陷修复非调参）。
2. **关键疑点（立项第一步必须先答）**：三臂对照用的是**旧判分口径**；此后判分侧两项已收口
   （剥头豁免 + 实质拒答措辞 `is_substantive_refusal`，2026-09-27 晚），臂1 同集单跑已达 **31/39 ≈ 臂2 的 31/39**
   （但构成混杂：口径①实测触发 1 次、②0 次、2 题话术抽签——见出账报告 §7）。
   **「负收益」有多少已被判分收口追平、行为侧还剩多少真差距，未知**——需把三臂产物用新口径重判后重算。
3. **拒答行为靠模型自觉，零代码兜底**【已验证】：出账报告 §3 观测首跑 39 题 `guard_replaced_*`/`finalized_refusal`/`fallback_next` 全为 0——
   拒答成功 25/25 全是模型自发写拒答话术；nightly 序列 19↔29 的话术抽签摆幅由此而来。
4. **新增单例（01319）**【已验证】：证据在手（15 items、hit@1_doc=1.0）、模型在答案里正确确认
   「未直接列出重组成本」（与 gold="0" 的事实前提一致），却不执行题面显式条件指令
   「If not explicitly outlined then state 0」→ 两次回放稳定拒答。**拒答模板压过指令遵循，且事实判断与最终行为脱节**。

## 1. 病灶两面（方向相反，修法不同，须分开验收）

| 面 | 表现 | 证据 | 错误方向 |
|---|---|---|---|
| **A：无答案题拒答不足** | 该拒不拒：注入相邻证据后强行作答（诱导作答）+ 话术抽签 | 出账报告 §2/§3：9 题 `first_search_injected` 直接作答（真诱导主体），稳定复现 2 题（ac71a2e2/68e1d163）；39 题夜摆 19↔29 | 假阳性（编答案风险） |
| **B：条件指令题拒答脱节** | 该答不答：题面给出缺省/条件指令（「未列出则答 0」），模型确认「未列出」后仍走拒答模板 | 01319 双回放稳定；同场 01328 同形态正常作答满分——非 prompt 全局问题，逐题触发 | 漏答（该得的分丢了） |

## 2. 诊断计划（先诊断后方案，数据现成不用重跑）

1. **三臂产物新口径重判**（0.5 天）：`data/evals/baseline_arms/{arm2_naive,arm3_gold_pdf}/predictions.jsonl` +

   重算三臂真实差距 → 决定「负收益」是否仍成立、残差多大。

4. 诊断产出 = 病灶占比表 + 修法候选排序，再进方案评审。

## 4. 判定与验收纪律（硬约束）

- **拒答判定必须用行为判定**（`answer_eval.is_refusal` / `is_substantive_refusal`），**禁止 GEval 判拒答题**——
  39 题的 gold 文本会让 GEval 把拒答判成通过（臂3「反超」假象来源）。
- **验收判据跑前写死 + 必须带参照臂**（预注册纪律）：主判据建议 = 39 题拒答集 `refusal_correct` 对照臂2 79.5% 不劣、
  pos-regress-60 正面误拒答保持 0、01319 形态哨兵题通过；三数一次预注册，跑后不改。
- 正面回归闸：pos-regress-60-v1（生产基线 56/56/57）——C1/C2 任何改动过这道闸才算数。
- 噪声地板：39 题小集合单跑翻转率高（夜摆 19↔29），**结论必须配对分析或多次采样**，单跑差值不定性。
