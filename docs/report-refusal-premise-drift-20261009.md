## 3. 判断与选项

- **定性**：标注与语料一致性问题（premise drift），不是模型行为缺陷；但污染两个读数（拒答集 + 主集 6 题）。
- **其余 10 道「欠拒」不属本缺陷**（源论文确不在库，前提仍成立），是行为侧问题：检索恒返 15 条候选 →「无证据」闸永真 → 模型拿近邻论文垫底硬答；修法=证据相关性闸（另案）。
- **6 题的处理选项（需拍板）**：

| 选项 | 动作 | 代价 |
| :--- | :--- | :--- |
| A（倾向） | 恢复为常规可答题（公开集 gold 从 git 恢复）+ 重判 + 主集重钉基线 | 动基线口径，需一次完整重判 |
| B | 从拒答集与主集合并件中摘除 6 题 | 主集变 1034 题，基线矩阵出现 skip，新旧口径不可直接比 |
| C | 不动题集，仅报告口径说明 | 零风险，但主集持续丢 6 分、拒答集读数持续失真 |

- **防再犯（独立于上面选项，建议无条件加）**：拒答前提对账断言——校验 39 题 gold 文档仍不在库，破例即报警并标记失效题；挂在 nightly（与素材检查同层）或语料扩充流程闸。
- **同型风险盘点（待做）**：任何「以语料状态为前提」的派生标注都可能过期。已知同类：知识库基线评测集的 3 道「超语料」拒答化题。
