# 三套外部拒答集审计（NoMIRACL-zh / SQuAD2-en / DuReader-robust-zh）

- 日期：2026-10-09；审计对象=本地 dev 机三套「外部基准」集（10-04/05 建，未同步生产）
- 数据来源：本地 bundle/构建脚本（`data/scratch/refusal-bench/`）+ 本地 eval 库 9 个 run（3 模型 × 3 集）
- 触发：业主观察到「Qwen3.6-35B-A3B 拒答率才 60%，dgx-flash 好很多」，怀疑测试集本身有问题

## 0. 结论

**三套集都有结构性缺陷，现状不能当「拒答能力 / 幻觉率」的度量。** 三类问题：

1. **「该拒」前提在语料里不成立的比例不小**：NoMIRACL 的官方负例里含直接回答该问题的段落；SQuAD2 的「不可答」只是「本段不可答」，整篇文章灌库后被别段泄答案。
2. **「该答」集的题目是搜索式历史提问**：DuReader 语料只有 2017 年旧答案，模型「守时拒答」被判错。
3. **判法只看话术**：拒答=文本标记匹配（不看证据、不判答案对错）→「答对了」「答得有据」与「编造」同罪。

## 1. 硬证据

### 1.1 同一道题三个模型全被判错，而答案就在语料里（NoMIRACL）

题 nmz_0017「世界上最大的湖泊在哪里？」——该题官方 non_relevant qrels 的负例列表内含段落（doc 471#30「亚洲」）原文：
**「位于亚洲西部的裏海是世界上最大的湖泊」**。

| 模型 | 答案（节选） | 判分 |
| :--- | :--- | :--- |
| Qwen3.6-35B-A3B | 「位于亚洲西部的裏海是世界上最大的湖泊…」 | 0（该拒没拒） |
| ds-flash | 「世界上最大的湖泊是里海（裏海），它位于亚洲西部」 | 0 |
| dgx3-flash | 「世界上最大的湖泊是**里海**…位于**亚洲西部**」 | 0 |

同类还有：法国民族、内蒙古农作物、六安邮编、纽约的银行、俄罗斯格斗赛……都是**语料原文直接含答案**。量化：NoMIRACL 46 个错答中，**38/46（83%）直接用检索证据原文作答**（最长公共子串 ≥12 字，其中 20 个 ≥30 字）；无一是凭空编造。

### 1.2 SQuAD2「该拒」半场的失败全部源于"整篇文章"语料

- 构造：8 篇文章；每题只把「题目所在段 + 每篇 ≤50 干扰段」灌库 → 整篇文章事实上都在库里。
- 32 个「该拒」错答，其证据 **32/32 全部来自本题所在文章** → 模型从文章别处找到了答案。
- SQuAD2 的官方「不可答」标注只保证「本段不可答」，与「整篇/整库不可答」不是一回事。

### 1.3 DuReader 的失败是"诚实拒答"而非答错

- 40 个错题中 **39 个是模型拒答**（不是答错）；源段落 38/39 确认在库（含答案）。
- 典型：汇率题 gold=「1美元=6.2053人民币」（2017 年话术）——模型识别出是旧数据、拒绝以旧充新；高考分数公布日期、游戏上市时间同理；「最好的手机杀毒」「哪家酒店好」这类主观题语料本就给不出定论。
- 从产品角度这些拒答是「诚实」，判分口径下全是 0 分。

## 2. 判断方法（代码级）

| 项 | 机制 | 问题 |
| :--- | :--- | :--- |
| 该拒题判分 | `is_refusal` **话术匹配**（中文标记/英文标记/正则/剥头豁免/实质措辞豁免）；命中=对，否则=0 | 不看证据、不判答案对错（correctness_checked=false）→ 有据作答与编造同罪 |
| 该答题判分 | LLM 语义判分（默认阈值） | 有噪声：抽样见"答案与 gold 同为 Tatiana Kuplich 却判 0.1" |

## 3. 模型对比（本地 9 run，该拒半场 / 该答半场）

| 集 | 半场 | Qwen3.6-35B-A3B | ds-flash | dgx3-flash |
| :--- | :--- | :--- | :--- | :--- |
| NoMIRACL-zh | 该拒 120 | 74 (61.7%) | **90 (75.0%)** | 72 (60.0%) |
| SQuAD2-en | 该拒 60 | 28 (46.7%) | 18 (30.0%) | **29 (48.3%)** |
| SQuAD2-en | 该答 60 | 47 (78.3%) | 44 (73.3%) | **48 (80.0%)** |
| DuReader | 该答 120 | 80 (66.7%) | 82 (68.3%) | **94 (78.3%)** |

- ds-flash 只在「全该拒」的 NoMIRACL 上领先（业主观察来源）；在 SQuAD2 的该拒半场反而垫底。**排名跨集翻转** → 三套集测的不是同一个稳定的能力。
- 「35B 拒答率 60%」中混着大量「从库里有据作答但被判错」的假失败 → 不能直接当模型质量结论。

## 4. 建议（要让它们变成可用指标）

1. **NoMIRACL**：逐题审计「语料是否含答案」（判官对 每题×其负例 判一遍），剔除/改判含答案的题；否则换真正无支持的语料。
2. **SQuAD2**：只灌「本题自己的段落」（恢复 per-paragraph 前提），或把口径改名为「本段不可答」并只在模型引用其它段时计数。
3. **DuReader**：剔除时效题（汇率/公布日期）与主观题（最好/推荐），或加时间标注、把「明智拒答」也算对。
4. **判法**：该拒题在「未拒」时加一次「答案是否被语料支持」判定，把「有据作答」与「编造」分开——那才是真幻觉率。
5. 在修好之前，这三套只适合做「弃答行为观察」，**不适合作为模型优劣或上线判据**。
