## 固定抽样

母集为上述 FinanceBench 全量 150 题，分层顺序：

1. `quality=correct`：73 题，抽 10。
2. 非 correct 且主答案空：4 题，全取。
3. 非 correct、非空且 `final_outcome=model_refusal_kept`：40 题，抽 10。
4. 其余非 correct：33 题，抽 6。

各层按 `SHA256("20261003:" + question_id)` 升序取前 N，选后不换题。
这是结果分层的诊断样本，历史通过率必为 10/30，不代表全量分布；不把样本正确率外推成产品分数。
记录 question_type 分布，不为追求题型配平修改抽样结果。

## 对照臂

| 臂 | 输入 | 用途 |
|---|---|---|
| H | 历史完整链路的冻结答案 | 保存原始产品表现，不重答 |
| R | 历史主 prediction 的 retrieved_items 原顺序文本 | 统一直答协议下的原证据对照 |
| K | 官方金证据页码对应的当前生产 canonical 原文与整表切片 | 页码 oracle，绕过候选召回，不修复表格内容 |
| O | 官方 evidence_text_full_page，缺省退 evidence_text | 官方金证据文本 oracle |

R/K/O 使用相同生成模型、提示词、采样参数与判分器。H 与 R 的差异包含提示词、编排和随机性，不能单独归因。
K 是整页定位，不是普通检索成绩；使用原页或跨页表格，可能带入其他页/无关信息，记录边界与长度。
K 不按金答案挑句、改列名或补数；O 不包含标准答案和 justification。金标只传判分器。
R 对没有 retrieved_items 的题保持空证据，不用猜测替代。

## 输入、生成与判分

- 被测：配置 `Qwen3.6-35B-A3B`，底层 `qwen3.6-35b`，显式 temperature=0.1，max_tokens=4096，instruct。
- 生成 system：`Answer the question using only the provided evidence. If the evidence is insufficient, state that clearly.`
- 生成 user：依次提供 evidence（编号及文档/页码）和原始 question，要求直接回答；所有臂同模板。
- 输入上限 100000 字符，超限记录 unsupported，不截断证据、不自动换题；输出截断视为生成失败，不缩短输入重跑。
- 单并发，逐题逐臂落盘；臂顺序按题目哈希轮换以减小顺序效应。
- 判分复用现有 `AnswerEvaluator.evaluate`，DeepEval、extra=0、judge `Qwen3.8-Flash-Next`，题集 semantic_threshold=0.65。
- 显式保留空答、拒答的现有判分语义。判官异常不算内容错，记录后最多一次固定重判。
- H 也以同一判分器重判一次，用于观察历史分数与当前判官差异；不覆盖历史结果。
- 当前无已配置、独立于判官的更强模型。第二生成模型臂暂不执行，不能由此作模型上限结论。
- 本轮不会运行完整生产检索链，因此不会测出新链路端到端耗时或检索修复收益。

## 关键翻转复核规则

第一采样完成后，固定选取最多 6 题：R/O 通过状态不同或 K/O 状态不同的题，按相同哈希升序。
对这些题重新生成 R/K/O 并判分一次，不改输入；无差异题不为凑满数量加入。
首次与复采都单独报告，不能择优计分。
人工证据复核覆盖这些差异题，必要时附上此前已发现的 Amcor、3M、动视暴雪案例；附加案例不并入30题统计。

## 判读与验收

- R 错、K/O 对：支持细粒度召回不足；仍需核对证据具体差异。
- K 错、O 对：检查表结构、OCR、页码范围、上下文干扰，不能直接全部记作解析缺陷。
- R/K/O 都错：检查任务理解、金标口径、数值推理；不能仅据一次生成判定模型能力上限。
- H 空、R 对：支持收尾/编排问题，但承认直答提示词和采样差异。
- 对照分数只作诊断，不写回 README、产品成绩卡或正式题集。
- 输出逐题对照、分层结果、判分异常、关键翻转复采、证据归因与下一项修复建议。
- 已确认的个案与未经全量量化的推断分开表述；不承诺特定涨分目标。
