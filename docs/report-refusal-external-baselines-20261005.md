## 1. 结论（TL;DR）

1. 三个外部拒答相关数据集（NoMIRACL-zh / SQuAD2-en / DuReader-robust，各 120 题）已建成题集并完成基线测量，
   三库落在**内测组**（生产未同步，2026-10-05 拍板）。
2. **本次最大发现【已验证】：守卫判据不看证据。** 语料清空对照 run 里 120 题全部强答、拒答 **0/120**——
   证据为零时系统零感知。守卫只防「模型嘴上说无法回答」，不管「证据在不在场」。
3. 守卫病灶从「两面」升级为「三面」：A 该拒不拒（NoMIRACL 35% 强答）、B 该答不答（01319 条件指令题）、
   **C 无证据强答（对照 run 0/120，新增）**。A/C 同源：判据缺失「证据在场」维度。
4. DuReader 34/120「假失败」定性完毕：拒答行为正确（答案确在语料外），判分必错——是**题集语料覆盖设计问题**，
   拆集改造即可变废为宝。
5. 改进首推 **P1 证据在场闸**（空证据/全低分证据 → 不走模型自觉、强制拒答路径），对照 run 给出其收益上限的直接估计。

## 4. 评价

### 4.1 守卫的证据盲区（本次最大发现）【已验证】

对照实验来源：三库迁移重建窗口期语料处于置空状态（ingest 状态文件与重建日志佐证），
在该窗口跑 DuReader 全集——所有题的检索层必然 0 证据。**属窗口期观测转正式对照**，
非事先设计的受控实验；run 未入 evals 系统，产物为手工汇总（见 §7 注意条）。
结果 120/120 全部强答、拒答 0。三面病灶拼图由此完整：

| 面 | 表现 | 证据 | 错误方向 |
|---|---|---|---|
| A 该拒不拒 | 语料无答案仍编造作答 | NoMIRACL 35% 强答（42/120）；39 题集 56.4%【它声称，待 D1 重判】 | 假阳性（编答案风险） |
| B 该答不答 | 证据在手、事实判断对，仍走拒答模板 | 01319 双回放稳定【已验证】 | 漏答 |
| **C 无证据强答（新增）** | **检索 0 条证据，模型照答不拒** | **对照 run 0/120 拒答【已验证】** | 假阳性（极端形态） |

关键定性：**守卫的判据是「模型的话术」而不是「证据的在场」**。历史观测（`guard_replaced_*`=0、
拒答成功 25/25 全模型自发）说明代码层守卫从未出场；对照 run 进一步证明——即便模型不认怂，
系统也没有任何一层拿「证据是否为零/是否低质」当拒答依据。这不是调参问题，是判据缺失。

现有基础设施其实已备好零件但没接线：相关性标注（`ANGINEER_EVIDENCE_GRADE`，低档 0.25「不得作结论依据」）
是 prompt 规则、靠模型自觉执行；上桌定员留痕（`all_scores.retrieval.admission`）已在跑。
「证据在场闸」只差把这两处信号变成**代码层硬判据**。

### 4.2 各集数字细读

- **NoMIRACL 65.0%**：与旧组 65.8% 一致 → 现状分数稳定、可作预注册基线。35% 强答题的检索证据多为
  「相邻主题」低相关条目（示例：英国国旗颜色数题，检索到的全是各国国旗比例描述）——正是
  「低分证据凑答案」形态，与出账报告 §2 归因互证。
- **SQuAD2 answerable 83.3% vs 旧 93.3%**：摆 6 题。库重建后 doc_id 全变、检索排序微移，
  叠加 526 题集实测约 12% 的单跑翻转噪声地板 → 单跑差值不定性，验收必须配对采样。
  拒答侧 40.0% 两轮逐分一致（巧合成分亦有，同为小样本）。
- **DuReader 34/120「假失败」**：逐题核过，全部是语料外时效内容（汇率、高考出分时间、姓氏人数统计、
  酒店推荐）——2019 年抽样语料不可能含答案。**拒答行为反而正确**，但题集 gold 期待作答 → 判 0。
  定性：非守卫缺陷、非检索缺陷，是**题集语料覆盖设计问题**。
- 正面项：三集引用正确 120/120×3、judge_failed=0、via_error=0——判分与故障面干净，分数可直接当基线。

### 4.3 与三臂「负收益」疑点的关系

三臂对照（臂2 朴素 RAG 79.5% ＞ 臂1 全链 56.4%）仍待 D1 新口径重判【它声称】。本次 NoMIRACL 65.0%
落在 39 题集同水位区间，不提供翻案证据也不加重——**D1 重判计划维持不变**。
对照 run 的价值在另一侧：它把「守卫该做什么」的答案从「更好prompt」改写为「加判据」，
直接改变 C2 候选的设计权重（见 §5）。

## 5. 改进建议（按优先级；每条含实际影响）

### P1 证据在场闸（新增候选 C5，建议并入 C2 双条件设计）

- **做法**：agent 循环在作答判定前查证据状态——检索 0 条非错误结果、或全部条目相关性 grade=低
  （复用 `ANGINEER_EVIDENCE_GRADE` 信号）→ 不依赖模型自觉，直接注入拒答倾向提示或走拒答模板，
  并以 `guard_replaced_*` 留痕（首次让守卫计数器非零）。
- **实际影响**：NoMIRACL 类「语料真没有」的题，理论收益上限即对照 run 反演的 0→120 题；
  现实受检索召回质量制约（有候选但 grade 判低 vs 真无候选须分档），预期把 65% 拉向 85%+ 档。
- **风险与闸**：误伤方向 = 检索该召回没召回时把可答题变成拒答。硬闸两条：pos-regress-60 正面误拒答
  保持 0；SQuAD2 可答题 83.3% 不劣（配对口径）。01319 型（B 面）不受影响——该闸只在证据弱时触发。

### P2 DuReader 拆集改造（零代码，题集 JSON 层）

- **做法**：34 道语料外题改造为 `refusal_expected=true` 子集（gold 语义反转），86 道语料内题保持应答。
  重导题集即生效（bundle 改造走 import 通道）。
- **实际影响**：把 34 个「假失败」变成有效的「不该拒误拒率」考题；DuReader 从 71.7% 的含噪口径
  变成两个干净口径（语料内作答 + 语料外拒答）。
- **代价**：一次重导 + 一次复跑确认；无生产部署依赖。

### P3 立项稿 D1 诊断前置不动摇

- 三臂重判 + 差集对账 + 01319 扩样照计划；本次证据**加强**而非替代。
- 顺带修订立项稿：§1 病灶表加 C 面（无证据强答）、§3 候选表 C2 吸收 P1 设计、判据表补 SQuAD2/NoMIRACL 基线。

### P4 维持原排序、不建议项

- **C3 话术稳定性降权**：对照 run 证明话术层是表层——判据层不修，模型认怂与否都是强答，
  固定话术句式的收益封顶。
- **C4 判分口径再收**：本次三集 judge_failed=0、拒答判定干净，边际继续为负，不做。
- **C1 条件指令优先**：与本次证据无交集，维持原位等待 01319 扩样数据。

### 不归守卫管的遗留

- 超时/挂起修复（首字存活线 c4ea561）已本地落地未部署——它治的是「故障吞错式拒答」的产生源头
  （本次三集 via_error=0 证明当前环境已不受扰），与守卫判据改造正交。
